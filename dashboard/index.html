How the value is built

Every number below comes from the snapshot’s own figures. No protocol name is hardcoded anywhere in the model.

  1. Base — $120M. What a $100M-TVL protocol is worth at neutral factors.
  2. Size — (TVL / $100M)^0.30. TVL sets the order of magnitude only: the biggest candidate outscores the smallest about 3× on size, not 50×. v1 used a near-linear size term and let giants sit on top even when their launch signal was weak.
  3. Momentum — 1 + 7-day TVL change, clamped to −40…+60%. A protocol growing 11% in a week is worth 11% more than the same protocol flat. Missing data counts as 0%.
  4. Maturity — 0.75 + 0.25 × min(age / 730 days, 1). The longer a protocol has run with no token, the closer a launch gets; under 120 days it takes a ×0.90 haircut. Unknown first day counts as 0.90.
  5. Breadth — +2.5% per chain past the first, to +30%. Multi-chain distribution is real reach.
  6. Category — ×1.08 / ×0.94 / ×1.00. Dexs, Lending, Yield, Restaking, RWA and Stablecoin Wrappers launch tokens most often; Insurance, CeDeFi, Chain and Staking Pools rarely do.
  7. Readiness — ×1.10 when the 7-day change is over +3% and the protocol runs on 3 or more chains: accelerating and expanding.

Implied values are this entry’s own claim, never a promise: a token may never be issued, and a farm plan is a way to use a protocol, not a guarantee of an airdrop.
